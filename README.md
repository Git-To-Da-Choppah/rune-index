# rune-index

Published card-index data for the Rune app. **Data only, built automatically.** Each release
holds a `manifest.json` and a gzipped SQLite index. There is no code here.

## Source and attribution
Card data derived from Scryfall bulk data (scryfall.com), trimmed and transformed for the Rune
app. Not affiliated with or endorsed by Scryfall. For general card data use
https://scryfall.com/docs/api/bulk-data.
